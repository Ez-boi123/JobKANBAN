# 本地求职记录配合独立云端邮件提醒

用户要求电脑休眠或关机时，手机仍能收到截止与预约提醒，因此已选择使用独立于本机运行的云端邮件提醒服务。求职记录继续以本地存储为主，仅同步公司、岗位、行动名称、相关时间、接收目标及必要的同步标识；完整备注、测评通行证和私人链接不随提醒同步。此边界在离线可达性与个人资料保留本地之间作出取舍，不将本机应用开放到公网，也不引入完整的云端求职看板。

## Consequences

- 云端只能按最后成功同步的安排发送邮件；离线修改、完成或取消行动后，需要明确显示同步状态，避免误以为旧提醒已经撤销。
- 每位用户配置自己的提醒服务，项目提供应用内配置向导和命令行部署教程；不由项目作者统一运营公共邮件平台。向导通过官方 Wrangler 完成用户授权、独立资源部署和云端 Secret 上传，保留本机检查点以便失败重试。SMTP 授权码不持久化到本机配置；运行凭证和同步密钥保存在 Git 忽略的个人配置位置。
- 实现采用 Cloudflare Workers 定时任务与 D1，使用共享随机密钥鉴权，163 独立客户端授权码存为云端 Secret。用户已确认此方向；真实 SMTP 连接与邮箱投递仍需用户账户实测，不代表已部署服务或启用个人信息同步。
- SMTP 接受后断线存在无法判定是否送达的情况；首版选择显式标记“不确定”、由用户确认后重试，不承诺严格一次投递。
